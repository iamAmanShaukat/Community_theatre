## Greenwich Community Theatre
* It is a movie ticket booking system project


## What BookMyShow Project can do : 
### I. For Admins : 
#### Admins can :-
  * Add a Movie.
  * Add Theater Seats
  * Create a Show for any Movie in the theater 
  * Create Show Seats for booking purpose
### II. For Users :
 #### Users can :-
  * Get the Show.
  * Can see the Show Seats 
  * Can Book the Ticket for available seats


## Different Models / Entities / (Table in MySQL) In the Project
1. User Entity
2. Movie Entity
3. Theater Entity
4. Theatre Seat Entity
5. Ticket Entity

 
## Tech-Stack Used : 
1. Spring-Boot
2. MySQL Database
3. OOPs
4. Java
